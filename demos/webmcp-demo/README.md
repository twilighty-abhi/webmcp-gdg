# Instructor WebMCP demo

Open `/demos/webmcp-demo/` in a local Chrome configured for WebMCP. The human UI and tools share the same `createApp` functions. Inspect these three tools: `searchEvents`, `getEventDetails`, and `registerForEvent`.

Suggested demonstration: search “cloud” → copy `evt-cloud` → inspect its details → register with an attendee name and email. The confirmation appears in the UI and state is saved locally.
